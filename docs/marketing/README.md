## Quick Reference

### Core Messaging

**Tagline:** "Golf Competitions Made Simple"

**Elevator Pitch:**
> The Nineteenth makes running social golf competitions dead simple. Create comps in minutes, score offline on-course, and watch live leaderboards update in real-time.

**Value Props:**
1. Create competitions in minutes (4-step setup)
2. Automatic player pairing
3. One phone scores the whole group
4. Works offline, syncs everywhere
5. Live leaderboards
6. Automatic handicap calculations

### Target Audience

- Social golf groups (4-20 players)
- Weekend warriors
- Corporate golf events
- Golf club social committees

### Key Differentiators

1. **Competition-first** (not individual scoring with leaderboard added)
2. **Group scoring** (one device for whole fourball)
3. **True offline** (full functionality without signal)
4. **Australian-built** (Golf Australia handicaps, local formats)
