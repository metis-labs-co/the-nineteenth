Score Entry: Detailed Stats UI Approaches

How should the new stats (miss directions, bunkers, hazards) integrate with the existing score entry per player?

Current layout per player: Score controls → Stats Row (FIR, GIR, Putts)

A

Contextual Expand (Recommended)

Keep existing stats row. Miss directions appear inline when FIR/GIR toggled off. Bunkers & Hazards in a collapsible "More Stats" row below. Minimal UI until needed.

Pros

  • Zero extra taps for basic scoring
  • Miss directions only appear when relevant
  • Bunkers/hazards hidden until expanded
  • Familiar pattern — extends existing row

Cons

  • Row can get wide on smaller screens when FIR/GIR both missed
  • Two levels of disclosure (miss pills + more stats)
B

Stats Bottom Sheet

Replace the inline stats row with a compact "📊 Stats" button. Tapping opens a bottom sheet with ALL stat categories in a clean form layout. Main score entry stays ultra-clean.

Pros

  • Main score entry stays completely clean
  • All stats in one organized place
  • Plenty of room for every stat category

  • Extra tap required for every stat entry
  • Slower for quick FIR/GIR/putts entry
  • Context switch between score and stats
C

Hybrid: Inline Basics + Sheet for Detail

Keep FIR/GIR/Putts inline (no extra taps for common stats). Add a small "+" button that opens a bottom sheet for bunkers, hazards, and miss directions. Best of both worlds.
