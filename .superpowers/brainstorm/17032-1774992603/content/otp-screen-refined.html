Empty State

First box has primary-colored border (focused). Verify button muted/disabled. Resend shows countdown timer.

Partially Filled

Filled boxes show digits with primary border. Current box has primary border (cursor). Unfilled boxes have subtle border.

All Filled → Auto-Submit

All 6 digits entered → auto-verifies. Verify button shows spinner. On error, boxes shake and clear for retry.

Interaction Notes

  • Verify button is visible (as in reference) but auto-submit triggers first when 6th digit is entered
  • Button serves as fallback if auto-submit doesn't fire (edge case)
  • Resend disabled for 30s with countdown, then becomes tappable: "Resend code" in primary color
  • Error state: boxes get colors.error border, error message appears above boxes, digits cleared
  • Back arrow navigates back to login screen (email entry)
