Solo Round Wizard Flow

Solo rounds have no partners step, so where does tee selection go?

A

Keep Tee Step (Recommended)

Course → Tee → Nine Type → Match Type → Ball Count

Tee step stays as-is for solo rounds. Nine Type comes after since it needs the tee context (front 9 vs back 9 ratings). Minimal change to existing solo flow.

B

Nine Type First, Then Tee

Course → Nine Type → Tee → Match Type → Ball Count

Pick how many holes first, then select tee. The tee step could show front 9 / back 9 specific yardages based on nine type selection.

C

Combine Tee + Nine Type

Course → Tee & Holes → Match Type → Ball Count

Merge into one step: select tee at top, then toggle 18 / Front 9 / Back 9 below. Fewer steps but a busier screen.
