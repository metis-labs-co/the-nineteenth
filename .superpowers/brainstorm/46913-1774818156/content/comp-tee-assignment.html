Competition: Where to Assign Player Tees

The organizer needs to set which tee each player plays off. Where does this happen?

A

Competition Settings Screen

Add a "Player Tees" section in the existing competition settings. Organizer sees all players and assigns tees per player.

Simple, discoverable. Works post-creation. But requires navigating to settings to set tees — might be missed.

B

Per-Round Detail Screen

On each round's detail page, show player list with tee picker. Tees are set per-round since different rounds may use different courses.

More contextual — tees are tied to a specific round's course. Makes sense when rounds use different courses with different available tees.

C

Both — Settings default + Per-round override

Competition Settings sets a "default tee" per player. Each round detail screen lets the organizer override for that specific round.

Most flexible but more complex. Good for multi-round comps where most rounds are at the same course but one or two differ.
