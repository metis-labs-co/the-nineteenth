Key Decisions Summary

9-hole scope Standalone rounds only
Per-player tees scope Standalone + Competitions
Wizard flow (group) Course → Nine Type → Match Type → Partners (inline tees) → Scoring Setup
Wizard flow (solo) Course → Nine Type → Match Type → Your Setup (tee + ball count)
Partner tee default Inherit creator's tee, override individually
No tees available Skip tee picker, use base handicap
Competition tees Default in settings + per-round override
Competition round overrides New competition_round_player_tees table
Scorecard display Colored tee dot next to player name
Side games on 9-hole Skins + Wolf both available
